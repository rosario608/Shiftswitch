## 1. Does your app collect data? — **Yes**

## 2. Do you or your third-party partners use data for tracking? — **No**

"Tracking" means linking data to third-party data for advertising or
advertising measurement, or sharing it with a data broker.

- The app contains no advertising SDK, no attribution SDK and no analytics SDK.
  The complete list of shipped third-party code is in §6.
- The app never requests `AppTrackingTransparency` permission, because it has
  nothing to ask about.
- `NSPrivacyTracking` is `false` and `NSPrivacyTrackingDomains` is empty in
  `PrivacyInfo.xcprivacy`.

**App Store Connect answer:** *No, we do not use data for tracking purposes.*
Do **not** add an ATT prompt.

## 4. Notes on two answers that are easy to get wrong

### The push token and install id

Storing an APNs token plus an app-generated install id is **not** "Device ID"
in Apple's sense. It is:

- generated per installation, not per device;
- unreadable by any other app;
- deleted when the user signs out, disables notifications, or the platform
  reports the token dead (`src/server/domain/push.ts`).

It is covered by *Identifiers → User ID* because it is linked to the account.

### The schedule

There is no Apple category for "work schedule". *User Content → Other User
Content* is the closest accurate one, and it is what `PrivacyInfo.xcprivacy`
declares. Do not use *Health & Fitness*: a duty roster is employment data, not
health data about the user.

## 7. Data collection is not optional, and account deletion exists

- Sign-in with a work Google account is required: the app's entire purpose is
  showing you *your* schedule inside *your* program. There is no anonymous mode
  to offer, so "Data is not linked to you" does not apply to the account data.
- Account deletion is available in the app at **You → Delete my account**, and
  also for an account that has not yet been assigned a program (Guideline
  5.1.1(v)). The flow shows what is deleted and what the program retains before
  the user confirms. Implementation: `src/server/domain/account.ts`,
  `src/app/api/account/delete/route.ts`, `mobile/src/screens/DeleteAccount.tsx`.
  Retention rationale: `docs/DATA_RETENTION.md`.
